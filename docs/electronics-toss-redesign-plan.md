## 2. 컴포넌트 스타일 스펙 (영상 실측, 1080px 기준 ÷2 = CSS px)

### GNB
- 검색바: 높이 ~52px, radius 완전 라운드 아님 — **12~14px**, 연회색 배지형 배경(우리 gray-100),
  좌측 돋보기 16px, 플레이스홀더 15px gray-400. 우측 바깥에 아이콘 2개(24px, gap ~20px).
- 장바구니 뱃지: 우상단 겹침 원형 ~16px, 흰 텍스트 11px bold. (우리는 찜 뱃지로 대체)
- 카테고리 탭: 텍스트 15px semibold, 항목 gap ~28px, **활성 = 회색 알약(gray-100) + 진한 텍스트**,
  비활성 = gray-600 텍스트만. 가로 스크롤, 스크롤바 숨김.

### 상품 카드 (2열 그리드, gap 12px)
- 이미지: 정사각 아님 — **세로가 살짝 긴 4:4.6~5**, radius **16px**, 배경색은 이미지가 채움.
- 좌상단 뱃지: 이미지 안쪽 8px, radius 8px, bold 13px, 흰 텍스트. (우리: --action-primary 배경)
- 우하단 하트: 이미지 안쪽 8px, 반투명 흰 하트 24px (채워지면 accent).
- 텍스트 블록(위→아래, 행간 촘촘 1.35):
  1) 상품명 15px, **2줄 클램프**, gray-900
  2) 보조 정보 12px gray-500 (👁 구매자수 | ★평점(리뷰수)) — 한 줄
  3) 가격 줄: 할인율 bold 17px accent + 최종가 bold 17px
  4) 상태 뱃지 줄: 파스텔 배지 11px (내일출발 등) + 적립 안내 11px gray-500
- 이미지 위 오버레이형 카드(음식 카테고리)도 있으나 **일반형만 채택** (오버레이형은 사진 품질 의존).

### PDP
- 헤더: 이미지 위에서는 투명 배경 + 아이콘만, 스크롤 시 흰 배경+타이틀 페이드인.
- 이미지 스와이퍼: 풀블리드, 우하단 "n|N" 인디케이터(반투명 알약), 좌하단 "비슷한 상품" 칩.
- 가격 블록: 뱃지 줄(내일출발+랭킹 칩) → 상품명 17px 2줄 → 할인율%+정가 취소선(gray-400)
  → **최종가 26px bold** + 라벨 → 부가 정보.
- 정보 행: 라벨 gray-500 14px + 값 + 우측 chevron, 행높이 ~44px, 구분선 없음.
- 탭: 2개("리뷰 (93개)" / "상품 정보"), 활성 밑줄 2px, sticky.
- 아코디언: 상세 이미지 ~2화면 높이에서 잘라 그라데이션 + "자세히 보기" 버튼(연회색 알약, 전체폭).
- Sticky Bottom Bar: 높이 ~64px, [하트][장바구니] 아이콘 보더 버튼 + 보조 버튼(연한 배경) +
  **주 버튼(채움, radius 12px, bold 16px)**. 아이콘과 버튼 gap 8px.

### 옵션 바텀시트
- radius 상단 24px, 핸들바 없음, 딤 배경. 슬라이드업 ~250ms ease-out.
- 내부: 가격 20px bold+무료배송 12px | 우측 수량 스테퍼(보더 radius 8px, - 1 +)
  → 쿠폰 할인 안내(파스텔 박스) → 상품명 14px gray-600 → 배송정보 카드(gray-50, radius 12px)
  → 안내문 → **전체폭 CTA "N원 결제하러 가기"** → 하단 캡션.

### 카테고리 서랍
- 좌측 사이드바 ~96px: 15px, 활성 = gray-100 라운드 배경.
- 우측: 섹션 헤더(대분류명 18px bold + "전체보기 >") + **원형 썸네일 72px** 3열 그리드,
  라벨 12px 중앙정렬. 섹션이 세로로 이어짐(사이드바는 스크롤 스파이).
- 로딩: 원형/사각 스켈레톤 그대로 재현.

### 2뎁스 목록 (카테고리 진입 후)
- 1행: 대분류 칩 가로스크롤(활성 밑줄 없음, 텍스트 강조)
- 2행: **원형 소분류 선택자**(56px 원 + 라벨, 활성 = accent 링 2px + accent 라벨)
- 3행: 정렬/필터 칩(필터 아이콘 칩, "추천순 ▾", 토글 칩) → 상품 그리드.

### 검색
- 진입 시 전체화면: 검색바 포커스 + "최근 본 상품" 가로 캐러셀 + 안내 일러스트 영역.
- 자동완성: 검색어 하이라이트(accent 컬러 부분 강조).
- 결과: 상단에 **카테고리 전용 필터 행**(라벨 bold + 값 텍스트 버튼들) → 정렬 칩 → 그리드.

## 4. 페이지별 적용 계획

### A. /electronics (렌탈 홈)
검색바+아이콘(GNB) → 가로스크롤 탭(렌탈 홈·카테고리·정수기·공기청정기·비데·침대·매트리스·특가상품)
→ 원형 숏컷 4 → "OO님을 위한" 대신 **"지금 많이 찾는 렌탈"** 2열 카드 그리드(무한 더보기).
배너 캐러셀은 콘텐츠가 없어 1장 고정(카테고리 프로모)으로 시작, 컴포넌트는 캐러셀로 제작.

### B. /electronics/category (카테고리 서랍)
좌 사이드바(대분류 3 + 인기) / 우 원형 썸네일 섹션 — 현 목차 페이지를 이 레이아웃으로 교체.
스크롤 스파이 + 스켈레톤 로딩 포함.

### C. /electronics/[category] (2뎁스 목록)
칩바(전 카테고리) + 원형 소분류 선택자(카테고리 이동) + 정렬/필터 칩 + 카드 그리드.
기존 filter_schema 필터는 "필터" 칩 → 바텀시트 유지, 약정/관리 칩은 존치.

### D. /electronics/search (검색)
전체화면 검색 전환: 최근 검색어(localStorage)+최근 본 상품(localStorage) → 자동완성(제품명/브랜드
매칭, 검색어 하이라이트) → 결과 상단에 해당 카테고리 filter_schema를 **필터 행**으로 노출.

### E. PDP /electronics/[category]/[slug]
모바일: 풀블리드 스와이퍼(이미지 0장이면 플레이스홀더 1장), 헤더 트랜지션, 토스형 가격블록,
정보 행(브랜드/관리주기/카테고리 위치), 리뷰·상품정보 대신 **기존 3탭(스펙분석/상세정보/추천) 유지**하되
탭바를 영상 스타일(밑줄+sticky)로 통일, 상세 아코디언은 기존 것 스타일만 교체.
**Sticky Bottom Bar**: [찜][공유] + "월 N원~ 신청하기" → **옵션 바텀시트**(약정/관리/판매조건 칩,
가격 실시간 갱신, 총 납부액) → "이 조건으로 신청하기" → 기존 apply 라우팅.
데스크톱: 현 2컬럼 유지(바텀시트는 모바일 전용 패턴), 카드·타이포만 새 토큰 적용.

### F. 찜 (신규, 프론트 전용)
localStorage `bl:wishlist` — 카드/PDP 하트 토글, GNB 뱃지 카운트, /electronics/wishlist 목록 페이지.
토스트("찜했어요 · 보러가기") 컴포넌트 공용화.
